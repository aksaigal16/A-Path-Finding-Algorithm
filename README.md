# A* Pathfinding Visualizer

An interactive pathfinding visualization tool built using Python and Pygame.
It demonstrates how the A* search algorithm finds a path from a start node
to a destination while navigating around obstacles.

## Key Features
- Interactive grid-based visualization.
- Custom start and destination nodes.
- Add and remove obstacles using mouse clicks.
- Visualize explored nodes and the resulting path.
- Manhattan distance heuristic for pathfinding.

## Technologies Used
- Python
- Pygame
- A* Search Algorithm
